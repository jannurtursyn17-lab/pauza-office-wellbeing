# Пауза

Откройте `index.html` в браузере. Сайт работает локально, без регистрации, сервера, базы данных, сторонних API и интернета.

Настройки таймера, отметки самочувствия и статистика пауз сохраняются только в локальном хранилище этого браузера. Они не отправляются руководству и не синхронизируются между устройствами. Случайная подсказка меняется каждые 5 минут.
